Data Quality & Anomaly Scan

Three robust outlier detectors run on the live data before it reaches a backtest: a GARCH(1,1) conditional-vol filter removes bad ticks (|R| > κσ), a Minimum-Covariance-Determinant Mahalanobis distance scores how anomalous today's joint move is across the book, and Local Outlier Factor flags density outliers. This is data cleaning and stress detection, not an alpha signal.
